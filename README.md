# Coaching in USA

A multi-page PHP + Bootstrap learning and professional development website.

## Main pages
- Home
- About
- Courses
- Course Detail
- Instructors
- Insights / Blog
- Contact
- Course Application / Admission
- Student Dashboard

The site is positioned as one unified Coaching in USA platform with flexible learning pathways across knowledge, ethics, healthcare, professional development, leadership and community impact.

## Run locally
```bash
php -S localhost:8000
```
Then open `http://localhost:8000`.
